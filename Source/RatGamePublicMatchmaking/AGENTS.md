# Project commitments

This is an unofficial community mod by Madara, without Sokpop endorsement.
No AI-generated artistic assets, image generation, or third-party asset packs.
Reuse installed native UI assets at runtime; never redistribute game assets or assemblies.
Keep the AI Usage Disclosure. Change no gameplay mechanics. No telemetry, global bans,
remote commands, developer privileges, or centralized player database.
Treat client input as untrusted. Identity must come from the authenticated host transport.
Keep offline tests distinct from live multiplayer results. Do not publish releases or
replace Nexus files without explicit user approval. Preserve v0.1.0-beta.1.
