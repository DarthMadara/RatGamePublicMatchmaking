Rat Game Public Matchmaking v0.2.0 - Host Moderation
Created by Madara. Unofficial community mod for Rat Game by Sokpop Collective.

Opt-in Public Hosting and a Public Lobbies browser, plus host-only Manage Players,
Kick, confirmed persistent host-local Steam ID bans, Manage Bans and individual
Unban. Moderation also works with Public Hosting OFF. No core gameplay changes.

Read START HERE.txt and INSTALL.txt. Windows x64 Steam Rat Game build 26403247 and
BepInEx 5.4.23.5 Windows x64 are required. The loader is a separate prerequisite;
new users do not need the previous beta. Existing users replace only the plugin
DLL while the game is closed, keeping configuration and bans. Launch via Steam.

November 22, 2026 - First confirmed organic public matchmaking session:
During testing with Eric, an unrelated player discovered the public lobby, joined
and played two games. Madara confirms successful Kick, Ban and Unban with two Steam
accounts on the corrected development implementation. Stable version stamping is
verified to preserve that implementation. The new stamped DLL has no separate live
session. See Validation/TEST-SUMMARY.txt and KNOWN LIMITATIONS.txt for exact scope.
