Rat Game Public Matchmaking — v0.2.0 installation
Author: Madara
Requires Windows x64 Steam Rat Game, checked on game build 26403247,
and BepInEx 5.4.23.5 Windows x64.

IMPORTANT: The v0.2.0 release ZIP contains the plugin, not a complete BepInEx loader.
The previous v0.1.0 beta ZIP had a different layout. Do NOT look for GameFiles
in the v0.2.0 package.

LOCATE THE GAME FOLDER
1. Exit Rat Game completely.
2. Steam Library -> Rat Game -> Manage -> Browse local files.
3. This opens the folder containing Rat Game.exe.
4. Extract RatGamePublicMatchmaking-v0.2.0.zip somewhere else first.

FIRST-TIME INSTALLATION
1. Download BepInEx 5.4.23.5 Windows x64 from its official release:
   https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
2. Follow BepInEx's setup instructions for the game directory.
   If you already have BepInEx installed, do not overwrite it blindly.
3. Copy the DLL from the extracted package at:
   BepInEx\plugins\RatGamePublicMatchmaking\RatGamePublicMatchmaking.dll
   to the same relative path under the Rat Game installation folder.
4. Launch Rat Game through Steam.

UPGRADING FROM v0.1.0 OR v0.2.0 DEVELOPMENT BUILDS
1. Exit Rat Game completely.
2. Back up your existing RatGamePublicMatchmaking.dll outside BepInEx\plugins.
3. Copy ONLY the new DLL from the v0.2.0 ZIP into:
   <Rat Game folder>\BepInEx\plugins\RatGamePublicMatchmaking\
   replacing the old RatGamePublicMatchmaking.dll.
4. Keep ALL existing configuration and banlists unchanged. The update package
   intentionally does not contain config files or banlist data.
5. Keep one active copy of the mod DLL under BepInEx\plugins.
6. Start Rat Game through Steam.

VERIFY
The main menu should have Public Hosting and Public Lobbies. In a host lobby,
the host should have Manage Players and Manage Bans controls. Check
BepInEx\LogOutput.log for mod startup/version diagnostics if necessary.

ROLLBACK
Exit Rat Game and restore your backed-up prior DLL. Keep your config and
banlist files unchanged.

KNOWN LIMITS
The mod targets game build 26403247 and BepInEx 5.4.23.5 Windows x64.
Invite/reconnect edge cases, host-restart ban persistence, every network race,
and some controller paths remain unverified. Kicking does not ban a user.
Host-local bans deny game connections; they do not forcibly remove someone
from Steam lobby membership.
