STEAM IDENTITY / MEMBERSHIP
Steam membership is separate from Netcode connections. Identity comes from
SDK-populated host callbacks and checked client/transport maps, not names or
client-provided IDs. The bundled wrapper's defective public Identity getter is
avoided via its inspected SDK-populated private identity field. Game/transport
updates require reinvestigation. Unsupported transports lack moderation controls.
Offline spoofing checks do not constitute a live adversarial security audit.

Bans reject game admission/traffic independently of public discovery/visibility.
This mod cannot forcibly evict Steam lobby membership; a rejected account may
still see/enter the Steam lobby and occupy a membership slot.

LOCAL BANS
Host-local only. No telemetry, global service or centralized reporting.
Unreadable/malformed storage, or a missing main file with a backup, blocks remote
admission instead of silently discarding bans. Preserve both files and repair
deliberately with the game closed. The .bak is the previous revision and may omit
the latest ban. Local filesystem administrators can edit their own banlist.
A saved ban remains active if disconnect fails; record the failure and retry.

PUBLIC MATCHMAKING
Steam metadata/results may lag. Full/withdrawn/starting lobbies can briefly remain
visible; joining rechecks conditions. Only waiting lobbies are advertised.
After a failed/cancelled public join, an old Steam request may need to settle;
restart before retrying the same lobby if needed. An empty list is not proof that
Steam networking works or that no hosts exist.

KNOWN NATIVE STARTUP ERROR
A StartScreen.GetBuildId exception occurred before Steam became ready in successful
beta/development sessions. Its native path was not changed. Check subsequent
readiness/hosting results rather than treating that early error as proof either way.

Supported target: Windows x64 Steam game build 26403247 / BepInEx 5.4.23.5.
No gameplay changes, redistributed game assets or AI-generated artistic assets.
