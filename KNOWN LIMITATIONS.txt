Rat Game Public Matchmaking - first beta limitations

NOT VERIFIED IN 0.1.0+waiting-browser.1

- Two-account public joining, including discovery by a nonmember, connection,
  both players spawning, scene sync, voice and actual remote gameplay.
- Friend/invite late joins. Native paths and global Steam admission are kept
  available during normal transitions, but their behavior has not been verified.
- Physical controller compatibility. Native navigation is reused and synthetic
  selection/movement checks were performed; this is not a hardware controller test.
- Real network races: delayed Steam metadata, simultaneous joins, last-slot
  contention, host withdrawal/start timing and owner migration between clients.
- Vanilla/older-mod interoperability, other mods, other loader versions,
  other operating systems, localization and every possible resolution/UI scale.

CHECKED LOCALLY IN THE VALIDATED REVISION

Normal Steam launch, single-account hosting, a filtered Steam query returning
the host's own waiting lobby, public withdrawal during native solo Co-op start,
ingame state, return with Public Hosting ON or OFF, native visibility withdrawal,
and advertised-host disconnect cleanup. These are local lifecycle checks, not
evidence that a second account can join. UI screenshots/bounds were checked at
1920x1080 at all five built-in scales, 1280x720 and 1366x768 at 140%, and
1280x1024 at 100%. The offline regression suite passed 100 checks.

STALE LISTINGS AND REMAINING RACES

Steam metadata and cached search results take time to update. Public joins
recheck the build, waiting state, public flag, public joinability, publication
generation, capacity and member-visible owner at the appropriate steps. An
observed withdrawal cancels that pending attempt. A changed publication requires
a fresh row; an old row cannot silently authorize a new advertising period.

These checks use information already delivered to the client. A change that
has not arrived yet, or happens after the final check/connection start, can
still race admission. There is no atomic host-side public-intent handshake.
A host crash can leave a stale listing until Steam catches up. Owner migration
before the first owner pin is another boundary. No complete race protection
is claimed, and a completed connection is not automatically ejected afterward.

The normal friends/invite/direct-ID path keeps the game's rules. Steam's
global nonjoinable switch would block invitees too, so normal match transitions
close the mod's public metadata gate without globally denying those native
connections. An unmodified client is not subject to this mod's public checks.

STEAM REQUESTS AND EMPTY RESULTS

Steam requests cannot always be cancelled. A local timeout does not release
a query lane until the underlying request settles. Failed joins can leave a
same-lobby callback quarantine; a retry may need the old callback or a restart.
The installed Steam wrapper returns null for both zero matches and a missing
SDK result. "No public lobbies returned" does not prove a successful empty search.

A native StartScreen build-ID exception has occurred before Steam finishes
initializing. The mod preserves that original exception and waits for a valid
positive live build before public operations; it does not bypass Steam setup.

Distribution in beta does not turn any NOT VERIFIED item above into a pass.
